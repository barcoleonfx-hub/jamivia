JAMIVIA LOGO KIT · v1.0 · November 2026

Start with jamivia-logo-guide.pdf (colours, clear space, minimum sizes).

svg/  pdf/   Vector, text converted to outlines. Use these for the label and all print.
png/         Transparent, 3000px. Use these for the web, documents and presentations.
social/      1080 x 1080 profile pictures (Instagram crops them to a circle).

Versions: stacked (primary), horizontal, wordmark, monogram.
Colours: forest (#1E392C), black, white.

Print: one flat colour, matte, no metallic. Match Forest to Pantone / CMYK on the printer's proof.
Font: Cormorant Garamond (SIL Open Font Licence), already outlined, so no font is needed.
